# Security

Caecilia is in alpha, and only the latest release gets fixes.

If you find a security problem, such as an organ or MIDI file that can run code or
corrupt memory, or a problem in the installer, please don't open a public issue.
[Report it privately on GitHub](https://github.com/alessonqueirozdev-hub/Caecilia/security/advisories/new),
or write to alessonqueiroz.dev@gmail.com.

Please include what you found and how to reproduce it.
